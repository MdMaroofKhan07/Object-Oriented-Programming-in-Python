## 💡 Example

```python
class Student:
    def __init__(self, name, roll_no):
        self.name = name
        self.roll_no = roll_no

    def display(self):
        print(f"Name: {self.name}")
        print(f"Roll No: {self.roll_no}")

student1 = Student("Maroof", 101)
student1.display()
```

### Output

```text
Name: Maroof
Roll No: 101
```
